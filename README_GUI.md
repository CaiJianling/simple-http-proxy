# 网络代理服务器 - 图形界面版

这是一个功能完整的网络代理服务器，具有现代化的图形界面和实时监控功能。

## 功能特性

### 核心功能
- **多协议支持**: HTTP/HTTPS/SOCKS5代理
- **参数配置**: 可配置主机地址、端口、客户端数量、缓冲区大小、转发延迟
- **实时控制**: 一键启动/停止服务器

### 监控功能
- **状态指示**: 实时显示服务器运行状态
- **连接统计**: 总连接数、活跃连接数、发送/接收字节数
- **运行时间**: 显示服务器运行时长
- **活跃连接**: 实时显示当前所有连接信息

### 可视化功能
- **实时日志**: 滚动显示服务器运行日志，支持不同类型日志的颜色区分
- **流量图表**: 动态显示网络流量趋势图，包含发送和接收流量
- **连接列表**: 表格形式显示活跃连接信息

## 安装和运行

### 环境要求
- Python 3.7+
- Windows/Linux/macOS

### 安装依赖
```bash
pip install -r requirements.txt
```

### 运行方式

#### 1. 直接运行（需要Python环境）
```bash
python proxy_gui.py
```

#### 2. 打包成可执行文件
```bash
# 安装PyInstaller
pip install pyinstaller

# 打包成exe文件
pyinstaller build.spec

# 打包完成后，exe文件在dist目录中
```

## 使用说明

### 界面布局
1. **控制面板**（顶部）
   - 服务器设置：主机地址、端口、最大客户端数、缓冲区大小、转发延迟
   - 控制按钮：启动/停止服务器

2. **状态面板**（左侧）
   - 服务器状态指示器
   - 实时统计数据

3. **日志面板**（右上）
   - 实时显示服务器运行日志
   - 不同类型日志有不同颜色标识

4. **连接列表**（左下）
   - 显示当前所有活跃连接
   - 包含IP地址、端口、连接时间、状态

5. **流量图表**（底部）
   - 动态显示网络流量趋势
   - 绿色线条表示发送流量
   - 蓝色线条表示接收流量

### 参数说明
- **主机地址**: 服务器监听地址，默认0.0.0.0（监听所有网卡）
- **端口**: 服务器监听端口，默认8080
- **最大客户端**: 允许的最大并发连接数，默认100
- **缓冲区大小**: 数据缓冲区大小，默认8192字节
- **转发延迟**: 数据转发延迟时间（毫秒），默认0

### 日志类型
- **连接日志**（绿色）：新连接建立信息
- **错误日志**（红色）：服务器运行错误信息
- **信息日志**（蓝色）：一般状态信息

## 技术特点

### 架构设计
- **多线程处理**: 每个客户端连接使用独立线程处理
- **非阻塞I/O**: 使用select实现高效的网络I/O
- **线程安全**: 使用队列实现线程间的安全通信
- **实时更新**: 定时器机制确保界面实时更新

### 可视化技术
- **matplotlib**: 专业的数据可视化图表
- **tkinter**: 跨平台的GUI框架
- **动画更新**: 实时图表动态更新

### 性能优化
- **内存管理**: 限制历史数据点数量，防止内存泄漏
- **高效更新**: 批量更新界面元素，减少CPU占用
- **错误处理**: 完善的异常处理机制

## 注意事项

1. **防火墙设置**: 确保防火墙允许监听端口
2. **端口冲突**: 避免与其他服务使用相同端口
3. **权限要求**: 某些端口可能需要管理员权限
4. **性能调优**: 根据实际需求调整缓冲区大小和最大客户端数

## 故障排除

### 常见问题
1. **端口被占用**: 检查端口是否被其他程序使用
2. **权限不足**: 尝试以管理员身份运行
3. **依赖缺失**: 确保所有依赖包已正确安装

### 日志分析
- 查看实时日志面板获取详细的运行信息
- 错误日志会用红色标识，便于快速定位问题
